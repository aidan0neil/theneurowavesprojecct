Release form for participants
=============================

The server emails participants a release form when they sign up.

- To use a PLACEHOLDER until your real form is ready:
  Run from project root:  npm run create-placeholder-release
  This creates release-form.pdf here. That file is attached to signup emails.

- When you have your real form:
  Save your official waiver/release PDF as:  release-form.pdf
  in this folder (overwriting the placeholder). No code changes needed.
  Restart the server if it is running.

Filename must stay:  release-form.pdf
